# 年号ならべバトル（仮）試作

歴史の出来事カードを年号順に並べる、1対1のオンライン対戦ゲームの試作です。

## ファイル

| ファイル | 中身 |
| --- | --- |
| index.html | アプリ本体（画面・ルール・通信） |
| cards.js | カードのデータ（CSV形式。ここを差し替えるとカードが変わる） |
| config.js | Firebaseの設定を貼る場所 |
| database.rules.json | Firebase Realtime Database のルール（試作用） |

## 動かし方

### デモモード（設定なし）
config.js が `null` のままなら、同じブラウザのタブ同士だけでつながります。
1つ目のタブで「部屋を作る」、別のタブ2つで合言葉を入れて入ると対戦できます。

### 別々の端末で対戦する（Firebase）
1. Firebaseコンソールでプロジェクトを作る
2. Realtime Database を作成し、database.rules.json の内容をルールに貼る
3. ウェブアプリを追加して、表示される設定を config.js の `window.FIREBASE_CONFIG` に貼る
4. このフォルダを GitHub Pages で公開する

※Firebaseのプロジェクト（nengo-battle、シンガポール）は作成済みで、config.js に設定が入っています。

## ルールの数字を変える
index.html の `RULE`（手札の枚数、1手の秒数、何本先取か など）を書きかえます。

## 試作の割り切り
- 生徒の情報はニックネームだけ。部屋を閉じると全部消えます
- ルールは「合言葉を知っていれば読み書きできる」だけの簡単なもの。カードの年号もブラウザに届いているので、詳しい人ならカンニングできます
- ジェムはその部屋の中だけで、次回には持ち越しません
